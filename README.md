# WeRead2Notion

将微信读书的书籍、划线和笔记同步到 Notion。

本项目使用微信读书 API Key 读取数据，并通过 GitHub Actions 定时同步到 Notion。新版不再需要复制微信读书 Cookie。

预览效果：https://malinkang.notion.site/weread2notion

> [!IMPORTANT]
> 默认使用 `safe` 安全同步模式：书籍页面会保留，微信读书自动同步内容会放在页面内的“微信读书同步内容”折叠区中。同步时只替换程序生成的块，折叠区内由你新建的普通内容会保留。
>
> 如需使用旧版“删除后重建”行为，可在 Action 中设置 `notion-sync-mode: replace`。旧模式下请不要在同步生成的书籍页面里添加重要内容。

## 同步模式

| 模式 | 行为 | 建议 |
| --- | --- | --- |
| `safe`（默认） | 更新书籍属性，只替换折叠区内程序生成的块 | 日常使用 |
| `replace` | 删除原书籍页面后重新创建 | 兼容旧模板或需要重置数据时使用 |

安全模式第一次运行时，旧版本已经生成的书籍内容会保留，同时创建新的同步折叠区；确认折叠区内容正确后，可以手动整理旧内容。旧版安全同步生成的同名子页面会在新内容写入成功后自动移除。请将个人补充内容作为独立块添加到折叠区内，不要直接改写微信读书生成的标题、划线或想法块。

## 完整书架与阅读报告

每次同步都会读取完整微信读书书架，不再只同步有划线和想法的书。电子书、有声书和文章收藏会作为独立条目写入书籍数据库；书籍模板中存在 `类型`、`最近阅读`、`置顶`、`私密` 等属性时会自动填充。

如需启用阅读日报和阅读看板，请在 Notion 新建一个普通页面（例如“微信读书阅读中心”），将 `weread2notion` 连接添加到该页面，然后把页面链接配置为 GitHub Secret：

```text
NOTION_REPORT_PAGE = 阅读中心页面链接
```

启用后，项目会在该页面下自动维护：

- `阅读看板`：书架总览、本月和本年阅读时长、阅读天数、阅读排行和偏好分类。
- `阅读日报/YYYY-MM-DD`：每日阅读时长、当天活跃书籍、新增划线和新增想法。

阅读时长使用微信读书按日统计；“活跃书籍”按当天最近阅读时间计算。日报和看板中的自动内容同样位于折叠区内，手动创建的独立块会被保留。
